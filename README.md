# Axl Lens Editor information site

Static project information and privacy disclosures for Axl Hazarika's private macOS editing project.

- Overview: <https://axlhazarika.github.io/axl-lens-editor-site/>
- Privacy policy: <https://axlhazarika.github.io/axl-lens-editor-site/privacy/>
- Developer website: <https://www.axlhazarika.in/>

This repository contains the informational website only. It does not contain application source, media, Lens packages, credentials or an application download. The website does not imply approval or endorsement by Snap.

## Hosting

GitHub Pages, deploying `main` from the repository root. No build step, JavaScript runtime, external font service or analytics script is required. `.nojekyll` keeps this a plain static site.

## Contents

- `index.html`: project overview
- `privacy/index.html`: app and website privacy policy
- `styles.css`: responsive styles
- `icon.svg`: site mark
- `app-icon.png`: opaque 1024 × 1024 version of the original site mark for the app-review form

Privacy disclosures describe the current private development build as of 31 October 2026. Update them before material data-handling changes or public application distribution.
