The workflow

From an existing file
to a finished edit.

  1. Import and organise

    Choose photos or videos on the Mac and organise them in a local project catalogue.

  2. Develop and apply a Lens

    Use source adjustments, a supported Camera Kit Lens, verified Lens parameters and post adjustments as separate stages.

  3. Compare and save

    Review the preview and export to a chosen local destination. Supported RAW inputs are developed into an SDR working copy; this does not make the edited output HDR.

Project status

Personal use, currently in development.

The application runs on the developer’s Mac using a native window and a local companion service. Camera Kit requires network access for authorisation, Lens delivery and SDK services. Compatibility depends on the Lens and workflow.

This is an informational website. The application is not offered for download or public use here. A request for Camera Kit production access is being prepared; this site does not represent approval or endorsement by Snap.
